নামাজ শিক্ষা — অফলাইন ওয়েবসাইট

ব্যবহার:
1. ZIP ফাইল Extract/Unzip করুন।
2. namaj_shikkha ফোল্ডারের index.html ফাইলটি Chrome-এ খুলুন।
3. ছবি দেখাতে assets ফোল্ডারটি index.html-এর পাশে রাখবেন।
4. হোস্টিংয়ে প্রকাশ করতে index.html ও assets ফোল্ডার একসঙ্গে আপলোড করুন।

নোট: এটি বাংলা শেখার সহায়িকা। আরবি উচ্চারণ, নামাজের মাসআলা ও মাজহাবভিত্তিক পার্থক্য বিশ্বস্ত আলেম/শিক্ষকের কাছে যাচাই করুন। ছবিগুলো শিক্ষামূলক ভেক্টর চিত্র, বাস্তব মানুষের ছবি নয়।
